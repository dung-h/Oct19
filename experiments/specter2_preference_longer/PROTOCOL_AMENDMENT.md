# Preflight correction

Before viewing any outer metrics, the first run completed one inner training partition through epoch16 and verified its epoch8 prediction matched the archived title-only epoch8 cache. It was interrupted in the next inner fit. No outer metrics were computed.

Code inspection found that the final test set contains duplicate paper groups shared with train. The existing SPECTER2 training helper permits this final-evaluation case when a save directory is supplied; the new wrapper had omitted that argument. The runner now supplies a partition-local save directory for test prediction, consistent with the existing `run_preference.py` final workflow. This does not change input, labels, training rows, optimizer, model, split, threshold selection or score. Partial inner0 predictions were produced by the same model function and arguments and are reused. `protocol_preflight.json` retains the initial protocol; `protocol.json` binds the corrected plan and source.

The first complete set of four inner partitions reached the inherited selector, which expects the original two arm names (`frozen`, `adapted`) and raised `KeyError` for the new checkpoint-specific family. No outer scores were produced. The selector is replaced with the same inner H threshold search and recall diagnostic, explicitly enumerating `adapted_8`, `adapted_16`, and `incumbent`, then selecting the policy by inner H. Model probabilities and candidate metric definitions are unchanged. `protocol_preflight2.json` preserves the intervening source/plan hash; the final protocol includes the revised chooser.

The next preflight reached a complete outer refit, then found that the archived outer run stores only the selected epoch (8), unlike inner caches, which store checkpoints1/2/4/8. It stopped before calculating the outer score. Replay checking now compares the new epoch8 probability matrix directly to the archived outer epoch8 matrix. `protocol_preflight3.json` retains the preflight hashes and the final protocol binds this replay-check correction.
